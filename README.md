# MyFitness 🏋️
MyFitness is a fitness tracking application built using **Flutter, Dart, and Firebase**.

##  Try the Live App

**[Launch MyFitness](https://myfitness-23453.web.app)**

##  Features

- Workout tracking and fitness progress
- Nutrition tracking
- AI fitness coach
- User profiles and authentication
- Social features and friends

##  Technologies

- **Flutter & Dart** — Application development
- **Firebase** — Authentication and backend services
- **JavaScript** — Supporting backend functionality
